# Helmet-Detection-and-ANPR
Computer vision-based helmet detection and automatic number plate recognition system using Python and YOLO.

# PROJECT OVERVIEW
A computer vision-based system designed to detect helmet usage among two-wheeler riders and recognise vehicle registration numbers using image processing and deep learning.


# OBJECTIVES
➤Detect two-wheeler riders.

➤Identify helmet and no-helmet cases.

➤Detect vehicle registration plates.

➤Extract registration numbers using OCR.

➤Integrate helmet detection and number plate recognition into one system.

# TECHNOLOGIES USED

➤Python

➤YOLO (Ultralytics)

➤OpenCV

➤OCR

➤Visual Studio Code

# PROJECT STRUCTURE

➤main.py – Main application

➤helmet_detection.py – Helmet detection module

➤number_plate_.py – Number plate recognition module

➤models/ – Model weights

➤test_images/ – Testing images

➤person_detection_test.py - Person recognition module for traffic and overlapping pedestrians
